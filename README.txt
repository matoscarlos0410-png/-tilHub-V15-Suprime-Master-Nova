GUARDADO
==================================================

ÚtilHub utiliza localStorage del navegador.

Las notas, tareas, compras, favoritos,
preferencias y algunos datos temporales
se guardan localmente en el dispositivo.

==================================================
GITHUB PAGES
==================================================

1. Crea un repositorio en GitHub.

2. Sube todos los archivos a la raíz.

3. Entra en:

Settings

4. Entra en:

Pages

5. Selecciona:

Deploy from a branch

6. Selecciona:

main

7. Selecciona:

/ (root)

8. Guarda.

GitHub generará la página.

==================================================
PWA
==================================================

La aplicación puede funcionar como PWA.

Para que el Service Worker funcione correctamente
en GitHub Pages se necesita HTTPS.
